Апокриф — сайт мастерской керамики и фарфора (Красноярск)

1. Как изменить тексты, цены и ссылки (без пересборки):
- Откройте файл dist/site-config.js (или public/site-config.js в исходниках) в любом текстовом редакторе.
- В разделе formats.items замените метки priceLabel («По записи», «В наличии», «Под заказ») на актуальные цены.
- При необходимости обновите тексты, адрес, режим работы и ссылки на WhatsApp / Telegram / ВКонтакте.
- Сохраните файл в кодировке UTF-8 и загрузите на хостинг.

2. Как опубликовать готовый сайт:
- Готовая сборка находится в папке dist/.
- Загрузите содержимое папки dist/ на Vercel, Cloudflare Pages, GitHub Pages или любой статический хостинг.
- Бэкенд и серверная маршрутизация не требуются (используются относительные пути).

3. Локальный запуск и пересборка (для разработчика):
- npm install
- npm run dev   — локальный предпросмотр
- npm run build — сборка продакшен-версии в папку dist/
