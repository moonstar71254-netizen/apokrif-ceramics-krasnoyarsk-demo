Апокриф — 3D WebGL-сайт мастерской керамики и фарфора (Красноярск) · v3

Стек: React 18, Three.js (@react-three/fiber + @react-three/drei), GSAP + Observer, Vite.

Что внутри (v3):
- Насыщенная 3D-композиция без коллизий (зазор между поверхностями >= 0.7 ед. на всех сценах и переходах):
  амфора на шлифованном гончарном круге, кружка ручной лепки с органичной ручкой, волнистая тарелка,
  пиала, 8 парящих 3D-пуговиц с фасками и отверстиями, 200 3D-частиц пыли/искр и живой печной GLSL-фон
- Процедурные PBR-текстуры 1024x1024 (Тёмный шамот, Молочный фарфор, Медная печь + концентрическая шлифовка круга)
- Интерактив на каждой сцене: раскрутка круга, hover-реакция посуды, свободное вращение по X/Y + ползунок обжига 900–1250°C, 6 форматов со своими 3D-фокусами
- 4 неповторяющихся GSAP-перехода (Split Horizontal, Orbital 85° Sweep, Exploded View, Overhead Pullback)
- Контакты и форматы вынесены в public/site-config.js (можно менять без пересборки)

Локальный запуск:
  npm install
  npm run dev

Сборка:
  npm run build                                 -> dist/
  npx vite build --config vite.ghpages.config.js -> dist-ghpages/
